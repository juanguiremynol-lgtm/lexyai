## Límites importantes

- Las correcciones de registros se leyeron del backend real. No se afirma que las variantes MCP estén desplegadas: el público sirve0.6.6.
- Las nuevas RPC de corrección/reclasificación permanecen cerradas; los once permisos ya liberados no se cambiaron. Se conserva endpoint e identidad OAuth.
- La sesión de preview está cerrada. No se acuñó sesión de un usuario real; por tanto no hay aceptación end-to-end autenticada ni certificación visual de las fichas. La página pública se abrió sin mutaciones.
- El SQL de contrato es lectura real, **no** prueba de comportamiento completo de las nuevas RPC. `sandbox_exec` no puede SET ROLE authenticated; ese intento falló y se retiró del arnés final, sin ampliar roles.
- No se ejecutaron scrapers ni se cambiaron horarios. El backfill administrativo legado `hearings-extract-backfill` aún apunta a `hearings`; se identifica como deuda, no se declaró corregido ni se ejecutó.
- No hay auditoría causal completa de recuperación/extracción de cada documento de Nicholls ni formalización completa origen/actual. Estos límites no se atribuyen automáticamente a Google Cloud.
